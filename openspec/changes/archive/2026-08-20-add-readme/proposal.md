## Why

プロジェクトにREADMEが存在せず、初めて訪れた人がこのユーザースクリプトが何をするものか、どうインストールするかが分からない。日本語話者・英語話者どちらにも伝わるよう、日本語版・英語版の両方を用意する（GitHub Issue #7）。

## What Changes

- `README.ja.md`（日本語）を新規作成する。プロジェクト概要、主な機能、インストール方法、開発者向け情報（セットアップ・ビルド・テスト）、ライセンスを記載する。
- `README.md`（英語）を新規作成する。同内容を英語で記載する。

## Capabilities

### New Capabilities
- `project-documentation`: プロジェクトの目的・インストール方法・開発者向け情報を説明するREADME（日本語・英語）を提供する。

### Modified Capabilities
(なし)

## Impact

- 新規ファイル: `README.md`, `README.ja.md`
- コードの挙動には影響しない（ドキュメントのみの変更）。
